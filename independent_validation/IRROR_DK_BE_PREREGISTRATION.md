# Locked independent holdout — DK and BE photovoltaic–wind–load forecasting and constrained battery dispatch

**Protocol frozen on 2026-11-01, before viewing any 2020 DK/BE target values or experimental outcomes.** This protocol is retrospective held-out testing with preregistered analysis, not prospective field deployment.

## Rationale and independent data
The previously examined Germany and Great Britain 2020 tests cannot be reused as fresh confirmatory evidence. Instead use Denmark (DK) and Belgium (BE), which were not the validation countries in the preceding photonic HRES study. Metered hourly system-wide actual demand, solar output and wind output come from the official OPSD Time Series v2020-10-06 file `time_series_60min_singleindex.csv` (local SHA256 `6a7f2bc571314cbf9c321cc03437691cd4be95c3a6f075e60ff99e8035c704c8`). Original country data are not local Hyderabad/Vizag microgrid measurements. Measurements are normalized using pre-2019 scales to a *hypothetical* grid-connected renewable/battery scenario; no measured India-site operational claim is permitted.

## Time boundaries and prediction convention
Training 2015-01-01 through 2018-12-31; residual-readout calibration 2019-01-01 through 2019-06-30; shrinkage selection only 2019-07-01 through 2019-12-31; locked final test January through September 2020. The target is net import `L(t+1) - PV(t+1) - W(t+1)`, with L/PV/W measured at country aggregate scale and rescaled to a 1.2 MW, 0.75 MW, 0.75 MW hypothetical microgrid. Predictors at issue time t use measurements no later than t, including lags 0, 1, 2, 24, 48, 168 and causal time cycles. No 2020 targets may be used to fit scalers, models, phase weights, feature selections or threshold parameters.

## Proposed testable component
**Interferometric Residual Readout with Operational Replanning (IRROR).** A strong digital direct net-load histogram gradient booster estimates `net(t+1)`. A deterministic physically inspired optical interference representation `sqrt(2) cos(xW+b)` with 96 fixed, seed-locked channels predicts its 2019-H1 forecast residual via ridge readout. Shrinkage alpha is selected from {0, 0.1, 0.25, 0.5, 0.75, 1} exclusively on 2019-H2. This is a *software phase-feature surrogate* and not measured photonic computing; learnable correction and measured hardware advantage are not claimed. The differentiating **testable engineering design** is phasor residual calibration and exact matched constrained replanning to isolate incremental value relative to its parent booster. Individual operations have literature precedents, so no global first-ever claim is assumed.

## Predeclared primary hypotheses and gates
H1: IRROR's 2020 net-load test RMSE is lower than the **same** direct HGB predictor in *both* DK and BE; report percentage change country by country. H2: with the **same** constrained optimization and every-six-hour replanning logic, the IRROR forecast yields lower total modeled battery operating cost than HGB forecasts in *both* DK and BE. H3 (secondary): either 6-hour-updated controller lowers modeled costs relative to a seasonal-forecast daily LP baseline. Strong two-region superior-learning-and-control claim REQUIRES H1 and H2 both succeed in both countries; bootstrap 95% CIs for paired squared-error and per-day costs must exclude zero in favorable direction in both regions. If alpha selects zero or tests fail, label unsuccessful; do not retune on 2020.

## Models and controls
Forecast baselines: net-load persistence lag 1; day-persistence lag 24; direct HGB (`max_iter=160, max_leaf_nodes=23, learning_rate=.07, l2_regularization=1`); phasor-only ridge (`96` fixed channels); IRROR. Chosen alpha is recorded. Cost policies: seasonal-day-ahead LP, 6-hour-updated LP with HGB one-hour forecast, and the *exact same* updated LP with IRROR one-hour forecast. Each future hour beyond first uses yesterday's corresponding measured net load; first-step forecasts are generated at t−1. All controllers use identical battery constraints, tariffs, prices, and actual-state information. There is **no access to actual net load before dispatch**. Country-scale profiles are translated to a simulated 1.2 MW nominal load, 0.75 MW PV, 0.75 MW wind, BESS 2 MWh, charge/discharge max .75 MW, round-trip charge/discharge efficiency .95/.95, state limits .3–1.8 MWh, daily start and final state .9 MWh. Import tariff 110/180/300 USD/MWh in hours 0–7 and 22–23 / 8–16 / 17–21 UTC, respectively; export remuneration 55 USD/MWh, throughput cost 15 USD/MWh of charge+discharge. UTC tariffs are invented scenario assumptions, not measured Denmark/Belgium prices. The grid is unconstrained; only battery operational feasibility is tested.

## Robustness and uncertainty
Moving block bootstrap on hourly paired squared-error differences, fixed 168-observation blocks, 2,000 resamples; 7-observed-day block bootstrap on paired daily costs, 2,000 resamples, deterministic seeds. Report missing hourly data and number of complete daily control episodes; drop days with any absent actual data and day-ago inputs rather than imputing. Report bootstrap 95% intervals and direction; no multiplicity correction is claimed (four region-by-endpoint checks are confirmatory, each required to succeed). Photonic model limitations include no optical chip, phase stability, laser energy, DAC/ADC or wall-clock inference measured.
